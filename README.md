
# Stormwatch Harbour

Agentic AI - Assignment 02

Name: Mahek Jabeen

## Description
A Python harbour simulation comparing baseline,
model-based and mock LLM agents.

## Features
- 24x16 harbour grid
- 10 dockworkers
- 4 berths
- Cargo delivery
- Storm warnings
- Agent safety testing

## How to Run
Run the simulation:
python run.py

Generate charts:
pip install matplotlib
python chart.py

## Results
Simulation results are saved in results.csv.

## Note
The Harbour Master uses mock LLM responses.
